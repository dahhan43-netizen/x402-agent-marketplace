## GitHub Pages Deployment

Create a `docs/` folder and put these files there:

```bash
mkdir docs
cp landing-page.html docs/
cp pay.html docs/
git add docs/
git commit -m "Add shareable pages"
git push origin main
```

Then share: `https://yourusername.github.io/x402-agent-marketplace/pay.html`

---

## Netlify/Vercel Drop

Just drag and drop the folder containing `pay.html` to:
- https://app.netlify.com/drop
